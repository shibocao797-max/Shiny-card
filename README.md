# 闪亮卡片

**把喜欢的图像、灵感与故事，收进一张可以旋转、探索和记录的卡片。**

闪亮卡片是一个属于自己的数字卡片空间。你可以从空白开始创建卡片，为它命名、挑选图片与外观；也可以在仓库中搜索它。搜索时，舞台上的粒子会散开，再聚合成对应的卡片。点开卡片，就能进入专属空间，继续记录与整理。

## 卡片，由你决定

- **制作自己的卡片**：自定义名称、分类、封面、比例、厚度，以及正反面的文字和主题。
- **近距离欣赏**：拖动卡片进行 360° 旋转，翻看背面，并自由调整大小。
- **看粒子重新聚合**：搜索卡片名称，让散开的粒子汇聚成你要找的那一张。
- **进入专属空间**：打开卡片，记录只属于这张卡片的想法与内容。
- **布置展示空间**：更换舞台背景，调整透明度，找到喜欢的展示效果。

## 开始使用

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

创建生产版本并在本地预览：

```bash
npm run build
npm run preview
```

## 数据保存在本机

卡片、文字记录和展示设置保存在当前浏览器中，卡片图片保存在浏览器本地存储。项目没有连接应用后端；清理浏览器网站数据或更换浏览器前，请先留意本地保存的内容。

## 技术

React、TypeScript、Vite 与 Three.js。
